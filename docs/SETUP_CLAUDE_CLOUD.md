# Setup na nuvem — Claude Code Cloud

1. Abrir https://claude.ai/code e iniciar sessão na conta pessoal Claude.
2. Conectar a conta pessoal do GitHub.
3. Escolher o repositório `brunoolmedo22-Paraguay/SEEDS2_C6_VIDEO`.
4. Confirmar que a sessão está no ambiente Cloud, não no terminal local do computador de trabalho.
5. Verificar se os arquivos binários foram adicionados a `assets/`; se não, completar a carga antes de produzir cenas.
6. Pedir para Claude ler `CLAUDE.md`, `docs/BRIEF_DIRECAO.md` e verificar materiais.
7. Usar branch `claude/storyboard-prototipo`, commits frequentes e PR para manter tudo acessível de casa.
8. Instalar bibliotecas (Node, Remotion, FFmpeg se necessário) no ambiente cloud com arquivos `package.json` e lockfile no repo.
9. Para produção e revisão, salvar código no GitHub; não depender de sessão temporária para manter artefatos.
